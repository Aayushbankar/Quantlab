Institutional Moats

Why traditional retail backtests fail live

Standard backtesting packages assume frictionless fills and report overfitted in-sample returns that dissolve the moment orders hit the National Stock Exchange.

Moat 01 · Statutory Indian Microstructure

The legal Indian delivery cost stack

While generic software applies a flat 0.05% brokerage, Pramaan implements the exact statutory tariff prescribed by SEBI and the Indian Stamp Act down to individual paise.

Empirical Finding: 48.2% of momentum strategy alpha is consumed by statutory friction alone.
Statutory Rate Card · Zerodha Delivery Standard
  • Securities Transaction Tax (STT): 0.10% delivery on both buy & sell legs
  • Depository Charges: flat ₹13.50 + 18% GST per debit transaction
  • Stamp Duty: 0.015% buy-side statutory charge (Indian Stamp Act)
  • NSE & SEBI Charges: 0.00297% turnover fee + ₹10/crore SEBI fee + IPFT
  • Almgren–Chriss Impact: square-root non-linear slippage on ADV
Marcos López de Prado Diagnostic Suite
  • 01Deflated Sharpe Ratio (DSR): Penalizes selection bias and trial count N across parameter sweeps.
  • 02Combinatorial Purged CV (CPCV): 45 overlapping test paths with non-zero purge and embargo intervals.
  • 03Probability of Backtest Overfitting (PBO): Measures how frequently in-sample winners underperform OOS.
  • 04Empirical Ground Truth: 133 configurations evaluated on NIFTY-50 — empirical PBO reaches 60.0%.

Native Linux Distribution

Packaged desktop application with embedded backend

Run Pramaan completely locally as a compiled desktop binary. The desktop app automatically monitors and auto-spawns the local FastAPI simulation engine on launch, requiring zero manual server orchestration.

Embedded Lifecycle Management

Auto-Spawn Architecture: Rust Tauri runtime probes 127.0.0.1:8000; if absent, spawns python3 -m src.api.main.
Clean Process Teardown: Backend child process terminates synchronously upon desktop window exit.
Zero Network Dependency: Runs completely offline using committed NIFTY-50 Parquet & SQLite cache.
