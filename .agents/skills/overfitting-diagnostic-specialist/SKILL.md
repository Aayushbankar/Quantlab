# Overfitting Diagnostic Specialist (GTU Unit 4 Focus)

This skill provides statistical validation theory, mathematical proofs, and diagnostic tools to identify and mitigate backtest overfitting and data snooping.

## 1. Marcos López de Prado's Deflated Sharpe Ratio (DSR)

When a researcher tests $N$ strategy variations or parameter combinations and selects the best one, the reported Sharpe ratio is inflated by data snooping.

### DSR Mathematical Proof
The expected maximum Sharpe ratio under the Null Hypothesis ($H_0$: pure noise across $N$ trials) is:

$$\text{E}[\max_n \widehat{\text{SR}}_n] = \text{SR}^* + \sqrt{\text{Var}(\widehat{\text{SR}})} \times \left( (1 - \gamma) \Phi^{-1}\left(1 - \frac{1}{N}\right) + \gamma \Phi^{-1}\left(1 - \frac{1}{N e}\right) \right)$$

where:
- $\gamma \approx 0.5772156649$ (Euler-Mascheroni constant)
- $\Phi^{-1}$ is the standard normal inverse cumulative distribution function (quantile function).
- $\text{SR}^*$ is the benchmark Sharpe ratio (usually 0).
- $N$ is the number of independent/correlated trials tested.

The asymptotic variance of the estimated Sharpe ratio accounting for non-normality is:
$$\sigma_{\widehat{\text{SR}}}^2 = \frac{1 - \widehat{\text{Skew}} \cdot \widehat{\text{SR}} + \frac{\widehat{\text{Kurt}} - 1}{4} \cdot \widehat{\text{SR}}^2}{T}$$
where $T$ is the number of daily returns observations.

The **Deflated Sharpe Ratio (DSR)** is the p-value:
$$\text{DSR} = \Phi\left( \frac{\widehat{\text{SR}} - \text{E}[\max_n \widehat{\text{SR}}_n]}{\sigma_{\widehat{\text{SR}}}} \right)$$

> **Interpretation**: If $\text{DSR} < 0.95$ ($p > 0.05$), the strategy's apparent performance cannot be statistically distinguished from random noise generated by multi-testing.

## 2. 2D Parameter Stability Surfaces (Unit 4 Redesign)

A robust trading rule must show **parameter neighborhood stability**:

```
Overfitted Fragile Strategy:
      Short Window
         10  15  20  25  30
Long 30 [ -2  -1  -3  -4  -2 ]
Win  40 [ -1  -2  +24 -1  -3 ]  <-- Overfit "Spike" (isolated needle in haystack)
     50 [ -3  -4  -2  -5  -1 ]

Robust Strategy:
      Short Window
         10  15  20  25  30
Long 30 [ +7  +8  +9  +7  +6 ]
Win  40 [ +8  +11 +12 +10 +8 ]  <-- Broad "Plateau" of profitability
     50 [ +6  +9  +10 +9  +7 ]
```

2. **"Profit Mirage" Waterfall**: Visual bar chart decomposing Gross Return $\rightarrow$ Fees $\rightarrow$ Taxes $\rightarrow$ Slippage $\rightarrow$ Out-of-Sample Decay $\rightarrow$ True Net Return.
