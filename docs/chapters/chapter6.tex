\section{The 6-Level WWWH Interrogation Matrix}
To ensure academic rigor, this section details brutal Q\&A matrices designed for the final ESE External Viva defense:
\begin{itemize}
    \item \textbf{Who assumes the execution risk?} The system architecture shifts execution risk to the routing layer, simulated explicitly in our latency models.
    \item \textbf{What defines your base state?} The base state is the unadjusted L1 tick data; adjusted data is strictly forbidden to prevent survivorship bias.
    \item \textbf{Where is the computational bottleneck?} Memory bandwidth during combinatorial purging, resolved via $\mathcal{O}(1)$ slicing.
    \item \textbf{When is the transaction graph finalized?} Strictly post-reconciliation of the $t+1$ bar.
    \item \textbf{Why utilize DSR instead of standard Sharpe?} Because retail engines suffer from pseudo-discovery; multiple testing inflates the expected Sharpe, which DSR mathematically deflates.
    \item \textbf{How do you prove zero look-ahead bias?} By auditing the order routing ledger, proving no timestamp $T_{fill}$ precedes $T_{signal\_generation}$.
\end{itemize}
